# GapLift — Stop Applying Blind

AI-powered resume gap analyser for India's job market, built with Claude AI.

## The Problem
Most job seekers apply to roles without knowing why they're getting rejected. 
The mismatch between their resume and the job description is invisible to them.

## What GapLift Does
- Reads your resume + job posting together
- Identifies exactly what's missing
- Generates 3 tailored resume versions (Technical, Leadership, Balanced)
- Highlights every suggested change so you stay in control
- Shows a skill-up roadmap — what to learn next

## Built For
Fresh graduates, career switchers, and mid-career professionals applying 
on Naukri, IIM Jobs, LinkedIn, and other Indian job platforms.

## Built With
- Claude AI (Anthropic) — gap analysis and resume generation
- Vanilla HTML, CSS, JavaScript
- Deployed on Vercel

## Why I Built This
As a Product Manager, I wanted to go through the full build cycle — 
identifying a real user problem, designing the experience, and shipping 
a working product end to end. GapLift is that exercise.
